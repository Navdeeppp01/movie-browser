# Movie Browser App

Search and display movie posters using the OMDb API. A stylish movie browser built with vanilla JavaScript.

## 🔧 Technologies Used
- HTML
- CSS
- JavaScript
- OMDb API

## 💡 Features
- Search by movie title
- Fetch and display movie poster and year
- Responsive card layout with hover effects
